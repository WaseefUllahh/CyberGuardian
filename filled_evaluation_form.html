Part G: Self-Reflection

1. What was the biggest usability challenge in this project, and how did you address it?

The biggest usability challenge was handling asynchronous state changes (like User Authentication, Quiz Scores, and Course Progress) across different screens without causing the user to face stale data.

I addressed this by implementing reactive Streams (using StreamBuilder in Flutter) across the critical components, such as the Dashboard Drawer and the Course Detail Screen. This ensures the UI automatically and instantly updates to reflect new progress (like unlocking the next lesson) without forcing the user to manually refresh the page or restart the app.

2. If you had two more weeks, what would you improve first, and why?

If I had two more weeks, I would improve the URL Scanner module by adding a visual analytics dashboard (using a charting library like fl_chart). This would provide a graphical overview of the user's scan history (e.g., showing a pie chart of safe vs. malicious links over time). This would better satisfy the 'Data visualization' heuristic and give users a clearer, more immediate understanding of their threat exposure over time.
